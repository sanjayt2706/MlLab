# ML Lab

Machine-learning laboratory work and experiments for learning practical ML concepts.

## Overview

This repository organizes machine-learning practice and experimentation, including work contained in the `project/` directory.

## Focus Areas

The repository is intended for practical exploration of:

- Data preprocessing
- Feature engineering
- Model training
- Model evaluation
- Experimentation with machine-learning workflows
